# 📸 PhotoVault

Telegram-бот для хранения съёмок — фото, видео и файлы по папкам с вложенностью.
Удобен фотографам: каждая съёмка — отдельная папка, а клиенту можно отправить
ссылку прямо на готовые файлы.

> Бот **не скачивает файлы на сервер**: он хранит Telegram `file_id` и отправляет
> файлы по нему, поэтому место на диске не расходуется.

## ✨ Возможности

- **Вложенные папки** — в каждой съёмке можно создать свои подпапки
  («Исходники», «Обработанные» и любые другие, до 4 уровней).
- **«Скачать всё»** — бот присылает всю съёмку вместе с подпапками одной кнопкой.
- **Ссылка для клиента** — по ссылке клиент получает файлы папки
  (только просмотр/скачивание, изменять ничего нельзя). Ссылку можно в любой
  момент пересоздать или отключить.
- **Заметки к папкам** — клиент, место, дата, пожелания.
- **Поиск по папкам** и **статистика** хранилища.
- **Защита от дублей** — один и тот же файл в папку дважды не попадёт.
- **Отмена последней загрузки** — если что-то ушло не туда.
- **Ограничение доступа** — можно разрешить пользоваться ботом только себе
  (клиенты по ссылкам при этом всё равно получат свои файлы).

## 🛠 Технологии

- Python 3.10+
- [aiogram 3](https://docs.aiogram.dev/) — фреймворк для Telegram Bot API
- [aiosqlite](https://github.com/omnilib/aiosqlite) — база данных SQLite
- [python-dotenv](https://github.com/theskumar/python-dotenv) — конфигурация через `.env`

## 🚀 Установка и запуск

```bash
# 1. Склонируйте репозиторий
git clone https://github.com/<ваш-username>/<repo>.git
cd <repo>

# 2. Создайте и активируйте виртуальное окружение
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux / macOS

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Создайте файл настроек из шаблона
cp .env.example .env          # Windows: copy .env.example .env

# 5. Впишите токен бота в .env (от @BotFather)

# 6. Запустите бота
python bot.py
```

## ⚙️ Переменные окружения (`.env`)

| Переменная       | Обязательно | Описание |
|------------------|-------------|----------|
| `BOT_TOKEN`      | да          | Токен бота от [@BotFather](https://t.me/BotFather). |
| `ALLOWED_USERS`  | нет         | ID пользователей через запятую (свой ID — у @userinfobot). Если задано, ботом сможете пользоваться только вы; клиенты по ссылкам всё равно получат свои файлы. |
| `DB_PATH`        | нет         | Путь к файлу БД, по умолчанию `vault.db`. |

## 🎮 Команды

| Команда      | Описание |
|--------------|----------|
| `/menu`      | Главное меню |
| `/folders`   | Мои съёмки |

## 📲 Как пользоваться

1. **Создайте съёмку** — «➕ Новая съёмка», например «Свадьба Иван и Мария, 12.06».
   Бот предложит сразу добавить стандартные подпапки «Исходники» и «Обработанные».
2. **Загружайте файлы** — откройте папку → «📤 Загрузить» и присылайте фото/видео/файлы.
   💡 Чтобы сохранилось оригинальное качество, отправляйте снимки как **файл**
   (скрепка → Файл), а не как «Фото».
3. **Скачивайте** — внутри папки кнопка «⬇️ Скачать всё» пришлёт всю съёмку
   с подпапками.
4. **Отправляйте клиенту** — «🔗 Поделиться» → бот даст ссылку вида
   `https://t.me/<бот>?start=s_<токен>`. По ней клиент получит только файлы
   этой папки, ничего менять не сможет.
